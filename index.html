What it does

Find duplicates

Scores every pair of names in one list. "Acme Inc." and "ACME Incorporated" score 100. "Smith Haulage" and "Smyth Haulage" score 97 and wait for you to decide.

Nothing is removed until you click Apply decisions. Matches scoring below 100 start unchecked, so you accept each one.

Free, with a 1,000-row limit

Almost Equal is free. Every feature in this version works on the first 1,000 rows of the file you load. That means a list holds at most 1,000 distinct values, and a run involves at most 499,500 comparisons.

There is no paid version and no price. Nothing here is for sale. If you need something this version does not do, such as comparing one list against another, or more than 1,000 rows, open an issue on GitHub and say what you were trying to do. Requests like that decide whether we build anything more.

Questions

What files can I load?

.xlsx and .csv are tested and work. The page also accepts .xlsm, .xls, .tsv and .ods, but nobody has loaded those yet, so we do not know whether they work. If you try one, tell us how it went in an issue. If a file will not load, the page tells you why and what to try.

How big can a list be?

The free version loads the first 1,000 rows of the file you load. Matching compares every distinct value with every other, so a list has at most 1,000 distinct values and a run involves at most 499,500 comparisons. Before a run the page shows how many values it will compare and how many comparisons that involves. It does not predict how long the run will take.

Does it work offline?

It is built to. The page makes no network requests and contains no code that could make one; we confirmed the first in a browser's network panel. We have not yet run it with the network adapter switched off, so test that yourself with the sample data before using your own file.

What can't it do?

It matches on one column at a time. It does not understand nicknames ("Bob" and "Robert"), match by sound, or read addresses. It never merges on its own: you approve every match. It does not change your original file. In this version it works on one list at a time and does not merge files.
